# FontMask

在浏览器中批量替换 TrueType 字体身份或字形。使用 Bun、Vite、SolidJS 和 Tailwind CSS；文件不会上传至服务器。

```sh
bun install
bun run dev
```

上传基底和供体的 `.ttf` / `.ttc` 文件。仅上传 TTF 时，只有一个供体文件就整批共用，否则两组按文件列表顺序一一配对。

任一侧含有 TTC 时，在「字面配对」里为每个基底字面选择供体。供体可来自任一已上传的 TTF，或任一供体 TTC 中的指定字面。同一个字面可以复用，集合大小无需一致。导出跟随基底格式，基底 TTC 的所有字面按原顺序写回一个 TTC，基底 TTF 则导出单个 TTF。

## 替换字体身份（默认）

对每一对字面，以所选供体为主体，从基底移植字体家族名、子家族名、全名和 PostScript 名称等命名字段，保留供体的字形、字符映射、度量、排版以及版权和许可声明。供体没有的字符不会补齐。修改后的原有数字签名将被移除。基底和输出可能同名，不建议同时安装。

基底和供体都支持使用 TrueType 轮廓的可变字体。输出保留供体的变化轴、命名实例和插值数据。

## 替换字形

替换按 Unicode 进行，保留基底的字体名称、样式标识、版权信息、字符映射和横向字距。供体缺字时保留基底字形；当多个字符共用一个基底字形时，使用首个匹配字符的供体轮廓。供体轮廓会换算为基底的字形单位，替换的轮廓不继承供体的 TrueType hinting。字形索引、边界和校验和会重建，失效的数字签名及设备度量会移除。供体字形宽度不同，仍可能出现视觉上的字距变化。

此模式需要静态基底。可变供体提供默认轴位置的轮廓。两种模式都要求单色 TrueType 轮廓。若完成了字形替换，原有的嵌入式单色位图也会移除，避免小字号仍显示旧字形。请确认拥有修改和分发字体的许可。

```sh
bun run build
```
